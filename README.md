# Kyle Schmitt: GIS Portfolio

Source for [kschmitt0.github.io](https://kschmitt0.github.io), a Jekyll site on GitHub Pages showcasing ArcGIS Pro projects from my graduate work in urban and environmental planning at ASU.

## Projects
- Grocery Inaccessibility in Sherman, TX: network and suitability analysis
- Landfill Suitability Index: weighted overlay raster model
- Great Smoky Mountains National Park: recreation and land cover layout
- Bike Infrastructure in Austin, TX: facility-type cartography
- Populations Near Historically Active Volcanoes, Pacific Northwest: hazard exposure mapping

## Structure
- `_projects/`: one Markdown file per project
- `_layouts/`: page templates
- `assets/`: styles, images, and PDFs

The site builds automatically with GitHub Pages.
